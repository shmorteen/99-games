# Acceptance Criteria

## KSA-018 - Lobby join and leave

Complete when:

1. An authenticated user can join a public waiting lobby.
2. A user cannot join the same lobby twice.
3. Player capacity cannot be exceeded.
4. Spectators do not consume player seats.
5. A private lobby rejects invalid credentials.
6. Leaving releases the player seat.
7. Host transfer occurs if the host leaves.
8. Concurrent join attempts cannot exceed capacity.
9. Tests cover all conditions.
